# Análise Empírica de Algoritmos de Ordenação
Este repositório contém a implementação e a análise empírica de diferentes algoritmos de ordenação em C++, desenvolvidos como parte de um estudo prático de desempenho computacional.

## Sobre o Projeto
O objetivo principal é avaliar o comportamento prático dos algoritmos em cenários de melhor e pior caso, utilizando arrays de inteiros com tamanhos crescentes (de 0 até 500.000 elementos).

## Principais Características
Implementações em C++: Código estruturado adotando a convenção de intervalos semi-abertos [esq, dir) para manipulação de índices.

Testes de Desempenho: Bateria de testes empíricos cobrindo diferentes cenários de entrada.

Análise Comparativa: Gráficos de desempenho e discussão crítica sobre a eficiência e a aplicabilidade de cada algoritmo.

Casos de Teste Padronizados: Arquivos de dados de pior caso organizados sob a convenção de nomenclatura p<num>v<val>.txt (onde num é o exercício e val é a quantidade de elementos).
